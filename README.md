# Site A.E.I – Aquitaine Équipement Industriel

Site vitrine statique pour une entreprise de tuyauterie et chaudronnerie industrielle.

## Fichiers

- `index.html` : contenu du site
- `style.css` : design responsive
- `script.js` : menu mobile et interactions
- `robots.txt` : directives moteurs de recherche
- `sitemap.xml` : sitemap de base
